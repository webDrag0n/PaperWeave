# 引用网络时间线视图设计

## 目标

在现有引用网络中增加按发表年份排布的横向时间线视图，让用户能直接观察研究随时间的演化及跨年份引用关系，同时保留当前网络视图。

## 方案

复用 Electron 渲染进程中的 `GraphView`、Three.js 和现有节点状态，不引入新的图形渲染栈或依赖。新增独立的纯布局模块，根据节点发表年份和当前节点顺序计算确定性坐标；视图切换只改变布局方式，不创建另一套节点、边或详情交互。

## 布局与视觉

- 工具栏新增“网络 / 时间线”分段切换，默认值为“网络”。
- 时间线中发表年份从左到右递增；相同年份的节点纵向紧凑排列，按当前图谱节点顺序保持稳定。
- 年份列使用固定水平间距，同列节点使用大于节点直径的垂直间距，整组节点围绕画布中心对齐。
- 顶部显示年份标签和淡色竖向分隔线；无法解析发表年份的节点归入最右侧“未知”列。
- 保留引用边。时间线模式下使用低对比度样式，避免长距离连线遮挡节点。
- 节点尺寸、颜色、当前论文高亮、选中状态和边方向沿用现有规则。

## 状态与数据流

- `app.js` 持有 `graphViewMode`（`network | timeline`）状态，并通过图谱顶部的分段按钮修改。
- `GraphView.setViewMode()` 接收视图模式；网络模式继续调用现有三维力导向布局，时间线模式调用年份布局，所有节点固定在 `z = 0` 的二维平面上。
- 搜索定位、星级筛选、跳数高亮、多选最短关联和详情栏继续消费同一组 `papers` 与 `links`。
- 切换回网络模式时重新运行现有力导向布局；不持久化临时坐标，也不修改文献数据。

## 交互

- 缩放、平移、旋转、节点点击、空白取消、Shift 多选、节点详情、搜索定位和双击打开均保持可用。
- 时间线模式在左下角显示导航工具条，支持年份下拉跳转、上一年、下一年、放大、缩小和适配全图；网络模式自动隐藏。
- 年份跳转使用平滑相机过渡并定位到目标年份列；到达首尾年份时禁用对应导航按钮，筛选后同步刷新可选年份。
- 星级筛选导致节点集合变化时，时间线立即按新集合重新排布；模式切换后相机自动适配当前节点。
- 小屏幕保持现有响应式图谱布局，视图切换按钮与筛选控件错位排列，不挤压图谱画布。

## 异常与边界

- 缺失、非法或不可解析的年份统一进入“未知”列，不抛错。
- 单年份、单节点和空图均产生合法坐标；空图继续显示现有空状态。
- 年份跨度很大时仍使用等距列，不按真实年份差拉伸，以避免稀疏年份造成过宽画布。
- 大量同年节点通过增加列高容纳，并保留缩放与自动适配，不截断节点。

## 测试与验收

- 单元测试覆盖年份分组、升序列、未知年份、确定性坐标、节点不重叠和空输入。
- Electron 渲染进程自测覆盖模式切换、按钮状态、筛选后年份布局、选中状态保留及网络视图恢复。
- 导航自测覆盖年份选项、下拉定位、前后年份按钮、缩放距离变化和适配全图。
- 使用项目现有 `npm run dev` 浏览器预览检查年份刻度、连线、筛选、节点详情和网络视图恢复。
- 运行新增布局测试、现有引用测试和完整 `npm run selftest`；所有新增检查通过后交付。
