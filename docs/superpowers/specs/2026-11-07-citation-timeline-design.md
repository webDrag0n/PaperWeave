# 引用网络二维时间线与上下游发展史设计

## 目标

将引用时间线定位为清晰的研究发展史视图：发表年份始终可读，交互以二维平移和缩放为主，并允许以单篇论文为中心，只查看其完整上下游发展脉络。原三维网络视图继续保留。

## 方案

复用 Electron 渲染进程中的 `GraphView`、Three.js 节点与连线，不新增依赖。年份布局与谱系计算由独立纯模块负责；画布顶部使用 HTML 年份标尺，避免三维文字在全图缩放时无法辨认。

## 布局与视觉

- 工具栏提供“网络 / 时间线”切换，默认值为“网络”。
- 时间线按发表年份从左到右等距排列；同年节点保持输入顺序并纵向避让，未知年份位于最右侧。
- 年份使用固定 `14px` HTML 标尺，随相机平移和缩放同步定位；标签过密时自动抽稀，当前年份始终高亮。
- 详情栏打开时，年份标尺缩短至详情栏左侧，适配全图同步调整相机可用宽度与中心，确保节点也不被遮挡。
- 时间线相机始终正视二维平面，节点位于 `z = 0`，参考线保留在节点后方。
- 引用边使用低对比度样式，节点颜色、选中高亮、多选路径和标签沿用现有规则。
- 单篇发展史顶部显示论文标题、上游数量和下游数量，并提供“查看全部”出口。

## 二维交互

- 时间线禁用三维旋转，左键和单指拖动只用于平移；普通滚轮整体缩放，Shift+滚轮仅横向缩放，Ctrl+滚轮仅纵向缩放，网络模式恢复原有旋转交互。
- 年份标尺保持固定 `14px`，论文标签通过相机距离补偿保持固定 `24px`，不随整体或单轴缩放改变字号；适配全图恢复两个轴的默认比例。
- 节点标签截断至 18 个字符并在节点上下交错排布；碰撞检测优先保留悬停、选中和高关联度标签，空间不足时暂时隐藏低优先级标签，完整标题通过悬浮提示查看。
- 图例在时间线模式明确提示“拖动平移”，网络模式提示“拖动旋转”。
- 保留年份下拉跳转、上一年、下一年、放大、缩小和适配全图；首尾年份禁用对应按钮。
- 节点点击、空白取消、Shift 多选、详情、搜索定位和双击打开均保持可用。

## 上下游发展史

- 论文详情提供“上下游发展史”入口，进入后自动切换到时间线，并清除星级限制以展示完整谱系。
- `from → to` 表示“from 引用 to”。从中心论文沿 `from → to` 递归收集参考文献上游，沿反方向递归收集被引下游。
- 两个方向均进行去重和环路保护；仅保留中心论文、上游、下游及其内部引用边，排除仅无向连通的旁支。
- 进入发展史后保持中心论文选中；点击“查看全部”恢复当前完整图谱，仍停留时间线。
- 图谱搜索只查找当前可见节点，避免在发展史模式中选中不可见旁支。

## 异常与边界

- 缺失或非法年份归入“未知”列；单年份、单节点、空图和无关联论文均产生合法结果。
- 引用环不会导致无限遍历；中心论文不会重复计入上游或下游集合。
- 年份跨度过大时仍使用等距列；同年节点过多时增加列高，并保留缩放与适配能力。
- 筛选导致年份集合变化时同步刷新标尺、下拉选项和导航状态。

## 测试与验收

- 单元测试覆盖年份布局、未知年份、确定性坐标、递归上下游、旁支排除、引用环和空输入。
- Electron 自测覆盖固定字号标尺、禁止旋转、二维提示、年份导航、缩放、完整发展史、中心选中及恢复完整图谱。
- 检查普通时间线和单篇发展史实际截图，确认年份清晰、摘要可见、旁支被排除。
- 运行布局测试、引用测试与完整 `npm run selftest`，全部通过后交付。
