# PaperWeave v1.5.0 — Agent 阅读能力与引用解析增强

## Agent API 与 MCP

- Agent API 升级至 v10，支持按页读取 PDF 正文、检索原文并返回高亮坐标，以及跨库查询论文和引用关系。
- 新增已有论文直接加入指定论文库、单条批注修改或删除、引用抓取与下载进度查询能力。
- MCP 扩展到 35 个工具，增加原始 PDF、逐页正文、跨库数据等 Resources，并提供精读、综述、研究洞察和兴趣高亮工作流。
- MCP 握手与科研助理指南加入取证、页码引用和原文定位规则，便于 Agent 更可靠地阅读论文并回写笔记与批注。

## 阅读与引用

- 改进无编号参考文献解析：清理重复页眉，支持完整姓名、Unicode 变音字符和断行 URL，避免相邻条目合并。
- 修复长作者列表被误识别为标题的问题，并改进正文引用悬浮卡片的标题与作者姓氏识别。
- 修复 PDF 页边有批注时正文偏移的问题；放大后可横向平移到论文两侧边缘。
- 阅读器支持论文内全文搜索，可通过右侧「搜索」页签或 `Ctrl+F` 打开，点击结果跳转到对应位置。

## 界面调整

- 移除顶栏插件按钮；浏览器插件、自动配对与论文导入能力保持不变。

## 升级说明

- 旧论文库、批注、笔记和引用关系可直接沿用，无需手工迁移。
- Windows 安装包尚未签名，首次运行可能显示 SmartScreen 提示。
- 本次提供 Windows x64 构建；macOS 与 Linux 请从源码构建。

## 构建产物

- `PaperWeave-1.5.0-win-x64-setup.exe`：Windows 安装包。

- `PaperWeave-Connector-1.5.0.zip`：Chrome / Edge 浏览器插件。
- `PaperWeave-1.5.0-win-x64-setup.exe.blockmap`：安装包增量更新索引。
