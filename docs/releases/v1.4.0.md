# PaperWeave v1.4.0 — 多维图谱筛选与论文库管理

## 图谱与论文库

- 图谱节点筛选支持星级与作者组合。作者可多选，也可点击论文详情中的作者直接切换筛选。
- 时间线视图 Shift 多选论文时，高亮它们之间的全部引用路径；网络视图继续显示最短关联。
- 左侧新增「全部已下载」，汇总各论文库及未加入任何论文库的论文与关系。
- 「设置」中可分别选择 PDF 下载目录和数据目录；现有文件会复制保留。PDF 目录立即生效，数据目录重启后生效。

## 引用与阅读

- 引用下载失败原因保存在论文数据中，并在引用页集中展示，支持逐条重试。Agent API 升级至 v9，下载失败结果提供可用于重试的条目信息。
- arXiv 论文年份优先根据编号与首页信息识别，并在下载入库时利用引用书目元数据补全信息；存量错误年份会在启动时修复一次。
- 图谱与阅读器往返时恢复仍在进行的抓取、下载进度。
- PDF 高亮、搜索命中和选区改为文字背景，保持文字清晰。
- 无窗口 API/MCP 模式不再创建渲染窗口，规避部分 Windows 环境的 GPU 子进程崩溃。

## 开发与构建

- 新增开发文档、贡献指南、安全说明、更新日志，以及快速回归和 Electron 端到端测试命令。
- Windows 安装包尚未签名，首次运行可能显示 SmartScreen 提示。

## 构建产物

- `PaperWeave-1.4.0-win-x64-setup.exe`：Windows 安装包。

- `PaperWeave-1.4.0-win-x64-setup.exe.blockmap`：安装包增量更新索引。
