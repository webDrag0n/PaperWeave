# PaperWeave v1.6.0 — 阅读批注、图谱与检索体验增强

## 阅读与批注

- 带文字批注的原文改为彩色下划线，重合下划线自动分配独立轨道，页边引线使用分离通道避免交叉。
- 批注支持 Markdown 编辑、预览及页边和列表渲染；选中文字可直接在本文内搜索。
- 阅读器可导出 `.pwpackage` 批注包，包含原始 PDF、论文信息和全部批注；从导入弹窗即可还原，并按批注 ID 与现有数据合并。

## 引用面板

- 阅读器和图谱详情的引用、被引面板新增独立搜索。
- 支持按时间、作者首字母或标题首字母排序，排序偏好跨面板同步并持久保存。
- 过滤后仍可使用展开、下载和 BibTeX 复制等原有操作。

## 图谱与时间线

- 修复时间线平移时年份标尺与参考线不对齐的问题。
- 修复图谱和时间线节点、标签的异常边界截断；相机适配会计入节点尺寸、标签和详情栏。
- 图谱旋转中心保持为全部节点质心，详情栏留白不再移动旋转目标。
- 顶栏搜索会高亮全部匹配节点并弱化其余节点，清空后恢复原有跳数配色。

## 论文库

- 所有排序方式均改为“分区标题 + 区内排序”：星级、添加年份、发表年份、标题首字母、作者首字母和引用关联数。
- 搜索过滤后仍保留分区结构。

## 升级说明

- 旧论文库、批注、笔记和引用关系可直接沿用，无需手工迁移。
- Agent HTTP API 与 MCP 契约保持不变，API 版本仍为 v10。
- Windows 安装包尚未签名，首次运行可能显示 SmartScreen 提示。
- 本次提供 Windows x64 构建；macOS 与 Linux 请从源码构建。

## 构建产物

- `PaperWeave-1.6.0-win-x64-setup.exe`：Windows 安装包。
- `PaperWeave-1.6.0-win-x64-portable.exe`：Windows 便携版。
- `PaperWeave-Connector-1.6.0.zip`：Chrome / Edge 浏览器插件。
- `PaperWeave-1.6.0-win-x64-setup.exe.blockmap`：安装包增量更新索引。
