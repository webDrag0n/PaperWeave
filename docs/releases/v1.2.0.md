# PaperWeave v1.2.0 — 自适应并行下载与引用增强

> 发布日期：2026-11-07。本文件按 GitHub Release 页面发布的说明原文补录，发布时仓库内未留存对应文件。

## 主要更新

- 多链接导入与引用全部下载支持自适应并行：初始并发 3，按延迟、超时和 429 在 1–6 之间调整。
- 下载后自动抓取引用与被引；相同 URL／引用任务去重，并发哈希复核避免重复入库。
- 阅读器引用页与 3D 节点侧栏实时显示完成数、等待数和当前并发。
- PDF 参考文献提取修复页序，支持无编号条目、机构作者、断词和附录截断；旧论文可按需从本地 PDF 重建。
- 测试论文 arXiv:2603.01966 可提取 37 条参考文献，真实 arXiv 引用在线识别通过。
